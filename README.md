# 資産形成ダッシュボード

個人の資産形成状況を管理・可視化するためのシングルページアプリ。  
サーバー不要・フレームワークなしのバニラ HTML/CSS/JS 構成。

## 特徴

- **バージョン表示** — ヘッダーにバージョンバッジ（`APP_VERSION` 定数で管理）
- **完全ローカル動作** — データは `localStorage` に保存（外部送信なし）
- **PWA 対応** — ホーム画面追加・オフラインキャッシュ（Service Worker）
- **印刷/PDF 出力** — ブラウザの印刷機能でダッシュボードを PDF 保存可能
- **ポイント管理** — 楽天ポイント等をポイント口座として管理し現金合計に反映
- **ゼロ依存** — Chart.js（CDN）のみ、npm 不要
- **データ移行対応** — v1/v2 フォーマットから v3 へ自動マイグレーション
- **未保存保護** — 記録タブで入力中にタイトルクリック/タブ切替すると確認ダイアログを表示
- **柔軟な種別管理** — 組み込み口座種別・銘柄種別の編集＋カスタム追加に対応
- **スマホ対応** — レスポンシブレイアウト（768px / 480px ブレークポイント）

## ファイル構成

```

├── index.html        マークアップ（~750行）
```

## 使い方

`index.html` をブラウザで直接開くだけで動作します。  
GitHub Pages: **https://nanopeta.github.io/asset-formation/**

### タブ構成

| タブ | 内容 |
|------|------|
| ダッシュボード | 総資産・ポートフォリオ・各種シミュレーション・詳細分析 |
| 記録 | 月次スナップショットの入力・保存 |
| 設定 | 銘柄・銀行口座・クレジットカード・証券会社・口座種別・銘柄種別の管理 |

### データ形式（localStorage キー）

| キー | 内容 |
|------|------|
| `asset-v3` | メインデータ（JSON） |
| `asset-v3-ts` | 最終更新タイムスタンプ（ISO 8601） |

## 主な機能

### ダッシュボード
- 総資産ヒーローカード（含み損益・先月比表示）
- 投資資産 / iDeCo / 現金 サマリーカード
- 対象銘柄 元本進捗ストリップ（到達予想日付き）
- NISA 枠使用状況（成長投資枠・積立投資枠・生涯枠・今年の投資計画）— 枠超過時は赤表示
- ポートフォリオ ドーナツチャート + 銘柄一覧 + 目標配分バー
- **クイックナビ**（ページ内スムーズスクロール・スクロール連動ハイライト）
  - シミュレーション6項目（資産シミュ / 配当カレンダー / iDeCoシミュ / FIRE / 取崩し / 税金概算）はドロップダウンにまとめてナビをコンパクト化
- **先月スナップ未記録リマインダー**（黄色バナー、記録タブへワンタップ遷移）

### 分析セクション
- **資産推移折れ線チャート**（期間フィルター: 全期間 / 1年 / 6ヶ月 / 3ヶ月）
- **到達シミュレーション**（対象銘柄は設定から選択可能）
- **分配金再投資シミュレーション**
  - 開始時評価額・元本・想定利回り・配当成長率・年次リターン・毎月積立・年数（5/10/20/30年）
  - 再投資なし切替、目標月収達成年の自動ハイライト、折れ線チャート付き
- **配当カレンダー**（月別受取スケジュール・棒グラフ）
- **全銘柄 配当シミュレーション**（NISA非課税 / 課税区分自動判定）
  - Excel 風フィルター（昇降順ソート・値チェックフィルター）
- **iDeCo 受取シミュレーション**（一時金・年金方式、退職所得控除・概算税額計算）
- **FIRE 達成シミュレーション**（必要資産・達成年数・プログレスバー）
- **FIRE 取崩しシミュレーション**（資産枯渇年計算・折れ線チャート・年次内訳テーブル）
- **税金概算**（配当税・潜在税・NISA/iDeCo非課税メリット、特定口座銘柄別内訳テーブル付き）
- **全銘柄 詳細分析**
  - 口座別合計・種別合計 — それぞれドーナツグラフ付き
  - 銘柄別一覧（Excel 風フィルター・縦横スクロール・ヘッダー＆A列固定）
  - **目標配分テーブル**（実績 vs 目標、買い増し目安金額付き）

### 記録タブ
- 月次スナップショット保存（Sticky ヘッダー）
- 未保存インジケーター（未保存時はパルスアニメーション表示）
- 過去月のデータ読み込み・編集・削除
- スナップショット一覧テーブル（比較・メモ付き）
- 保存後の月次サマリーモーダル（総資産・先月比・含み損益）
- iDeCo 累計拠出元本「累計拠出を推計」ボタン
- 前月コピーボタン（全フィールド一括コピー）
- **ポイント残高入力**（設定でポイント口座を登録後に表示）
- Ctrl+S でスナップショット保存
- 🖨 印刷/PDF ボタン（`@media print` CSS 方式）

### 設定タブ
- 保有銘柄 CRUD（ドラッグ&ドロップ並び替え、スポット購入計画、証券会社紐付け）
- iDeCo 銘柄 CRUD
- 銀行口座 CRUD
- クレジットカード CRUD（引き落とし口座紐付け）
- **ポイント口座 CRUD**（楽天ポイント等を登録、残高は現金合計に加算）
- **証券会社 CRUD**（銘柄への紐付け・楽天証券CSVの削除スコープ制御）
- 口座種別 CRUD（組み込み編集・非課税フラグ・カスタム追加・全種別ドラッグ並び替え・グラデーション順カラーピッカー・未使用色ランダム選択）
- 銘柄種別 CRUD（組み込み編集・カスタム追加・全種別ドラッグ並び替え・グラデーション順カラーピッカー・未使用色ランダム選択）
- 対象銘柄セレクト・USD/JPY 設定
- iDeCo 開始月・月次拠出合計設定
- 設定パネルのモーダルポップアップ表示（背景クリック・ESCキーで閉じる）
- **ブランデッド確認ダイアログ** — 削除・CSV インポート・未保存変更の警告をアプリ内モーダルで表示
- データ管理
  - 全体バックアップ JSON エクスポート / インポート
  - 設定のみ JSON エクスポート / インポート
  - 記録 CSV エクスポート
  - **楽天証券 CSV インポート**（証券会社スコープで削除対象を制御）

## 対応口座種別

| コード | 表示名 | 非課税 | 備考 |
|--------|--------|--------|------|
| `nisa-growth` | NISA成長投資枠 | ✅ | 組み込み・編集可 |
| `nisa-tsumitate` | NISA積立投資枠 | ✅ | 組み込み・編集可 |
| `specific` | 特定口座 | — | 組み込み・編集可 |
| `old-nisa` | 旧NISA | ✅ | 組み込み・編集可 |
| カスタム | 任意 | 設定可 | 設定タブから追加 |
| iDeCo | iDeCo | ✅ | 別管理（idecoHoldings） |

## 対応資産種別

| コード | 表示名 | 備考 |
|--------|--------|------|
| `fund` | 投資信託 | 組み込み・編集可 |
| `domestic-stock` | 国内株式 | 組み込み・編集可 |
| `us-stock` | 米国株式 | 組み込み・編集可 |
| `other` | その他 | 組み込み・編集可 |
| カスタム | 任意 | 設定タブから追加可能 |
