# 資産形成ダッシュボード

個人の資産形成状況を管理・可視化するためのシングルページアプリ。  
サーバー不要・フレームワークなしのバニラ HTML/CSS/JS 構成。

## 特徴

- **完全ローカル動作** — データは `localStorage` に保存（外部送信なし）
- **ゼロ依存** — Chart.js（CDN）のみ、npm 不要
- **データ移行対応** — v1/v2 フォーマットから v3 へ自動マイグレーション
- **JSON バックアップ** — エクスポート/インポートでデータ管理

## ファイル構成

```
asset-formation/
├── index.html        マークアップ（~530行）
├── style.css         スタイル（~225行）
├── app.js            ロジック（~600行）
├── CLAUDE.md         AI向けコードベース概要
├── README.md         このファイル
└── tasks/
    ├── todo.md       現行タスク管理
    └── lessons.md    教訓・注意事項
```

## 使い方

`index.html` をブラウザで直接開くだけで動作します。  
GitHub Pages: **https://nanopeta.github.io/asset-formation/**

### タブ構成

| タブ | 内容 |
|------|------|
| ダッシュボード | 総資産・ポートフォリオ・各種シミュレーション・詳細分析 |
| 記録 | 月次スナップショットの入力・保存 |
| 設定 | 銘柄・銀行口座・クレジットカード・口座種別・銘柄種別の管理 |

### データ形式（localStorage キー）

| キー | 内容 |
|------|------|
| `asset-v3` | メインデータ（JSON） |
| `asset-v3-ts` | 最終更新タイムスタンプ（ISO 8601） |

## 主な機能

### ダッシュボード
- 総資産ヒーローカード（含み損益・先月比表示）
- 投資資産 / iDeCo / 現金 サマリーカード
- 楽天SCHD 元本進捗ストリップ（到達予想日付き）
- NISA 枠使用状況（成長投資枠・積立投資枠・生涯枠）
- ポートフォリオ ドーナツチャート + 銘柄一覧
- クイックナビ（ページ内スムーズスクロール）

### 分析セクション（常時表示）
- 資産推移 折れ線チャート
- SCHD 到達シミュレーション
- SCHD 分配金再投資シミュレーション（10年複利・月換算）
- 全銘柄 配当シミュレーション（NISA非課税 / 旧NISA非課税 / 課税区分対応）
  - 列ヘッダー Excel 風フィルター（昇降順ソート・値チェックフィルター）
  - フィルター適用時に合計行を可視行のみで再計算
- 全銘柄 詳細分析（口座別・種別合計・損益率）
  - 列ヘッダー Excel 風フィルター
  - 合計行（フィルター連動）

### 記録タブ
- 月次スナップショット保存（Sticky ヘッダー）
- 未保存インジケーター
- 過去月のデータ読み込み・編集
- スナップショット一覧テーブル

### 設定タブ
- 保有銘柄 CRUD（ドラッグ&ドロップ並び替え）
- iDeCo 銘柄 CRUD
- 銀行口座 CRUD
- クレジットカード CRUD
- 口座種別 CRUD（カスタム追加・編集・削除）
- 銘柄種別 CRUD（カスタム追加・編集・削除）

## 対応口座種別

| コード | 表示名 | 備考 |
|--------|--------|------|
| `nisa-growth` | NISA成長投資枠 | 組み込み |
| `nisa-tsumitate` | NISA積立投資枠 | 組み込み |
| `specific` | 特定口座 | 組み込み |
| `old-nisa` | 旧NISA | 組み込み |
| カスタム | 任意 | 設定タブから追加可能 |
| iDeCo | iDeCo | 別管理（idecoHoldings） |

## 対応資産種別

| コード | 表示名 | 備考 |
|--------|--------|------|
| `fund` | 投資信託 | 組み込み |
| `domestic-stock` | 国内株式 | 組み込み |
| `us-stock` | 米国株式 | 組み込み |
| `other` | その他 | 組み込み |
| カスタム | 任意 | 設定タブから追加可能 |
