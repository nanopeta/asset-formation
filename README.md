# 資産形成ダッシュボード

個人の資産形成状況を管理・可視化するためのシングルページアプリ。  
サーバー不要・フレームワークなしのバニラ HTML/CSS/JS 構成。

## 特徴

- **完全ローカル動作** — データは `localStorage` に保存（外部送信なし）
- **ゼロ依存** — Chart.js（CDN）のみ、npm 不要
- **データ移行対応** — v1/v2 フォーマットから v3 へ自動マイグレーション
- **柔軟な種別管理** — 組み込み口座種別・銘柄種別の編集＋カスタム追加に対応

## ファイル構成

```
asset-formation/
├── index.html        マークアップ（~590行）
├── style.css         スタイル（~230行）
├── app.js            ロジック（~680行）
├── CLAUDE.md         AI向けコードベース概要
├── README.md         このファイル
└── tasks/
    ├── todo.md       現行タスク管理
    └── lessons.md    教訓・注意事項
```

## 使い方

`index.html` をブラウザで直接開くだけで動作します。  
GitHub Pages: **https://nanopeta.github.io/asset-formation/**

### タブ構成

| タブ | 内容 |
|------|------|
| ダッシュボード | 総資産・ポートフォリオ・各種シミュレーション・詳細分析 |
| 記録 | 月次スナップショットの入力・保存 |
| 設定 | 銘柄・銀行口座・クレジットカード・口座種別・銘柄種別の管理 |

### データ形式（localStorage キー）

| キー | 内容 |
|------|------|
| `asset-v3` | メインデータ（JSON） |
| `asset-v3-ts` | 最終更新タイムスタンプ（ISO 8601） |

## 主な機能

### ダッシュボード
- 総資産ヒーローカード（含み損益・先月比表示）
- 投資資産 / iDeCo / 現金 サマリーカード
- 対象銘柄 元本進捗ストリップ（到達予想日付き）
- NISA 枠使用状況（成長投資枠・積立投資枠・生涯枠）
- ポートフォリオ ドーナツチャート + 銘柄一覧
- クイックナビ（ページ内スムーズスクロール）

### 分析セクション（常時表示）
- 資産推移 折れ線チャート
- **到達シミュレーション**（対象銘柄は設定から選択可能）
- **分配金再投資シミュレーション**
  - 開始時評価額・開始時元本・想定利回り・毎月積立・年数（5/10/20/30年）
  - 再投資なし切替（取り崩しモードとの比較）
  - 元本・評価額・年間分配金・月換算・累計分配金を表示
- **全銘柄 配当シミュレーション**（NISA非課税 / 課税区分自動判定）
  - 口座種別の taxFree フラグに基づく非課税判定
  - Excel 風フィルター（昇降順ソート・値チェックフィルター）
  - フィルター適用時に合計行を可視行のみで再計算
- **FIRE 達成シミュレーション**
  - 希望月収・取り崩し率・想定年利・月次積立から達成予想年月を算出
  - 現在の取り崩し可能月額・必要資産額をリアルタイム表示
- **全銘柄 詳細分析**（口座別・種別合計・損益率）
  - Excel 風フィルター・合計行（フィルター連動）

### 記録タブ
- 月次スナップショット保存（Sticky ヘッダー）
- 未保存インジケーター
- 過去月のデータ読み込み・編集・**削除**
- スナップショット一覧テーブル（スクロール固定・ヘッダー固定）

### 設定タブ
- 保有銘柄 CRUD（ドラッグ&ドロップ並び替え）
- iDeCo 銘柄 CRUD（ドラッグ&ドロップ並び替え）
- 銀行口座 CRUD（ドラッグ&ドロップ並び替え）
- クレジットカード CRUD（ドラッグ&ドロップ並び替え）
- 口座種別 CRUD（組み込み編集・非課税フラグ設定・カスタム追加・ドラッグ&ドロップ）
- 銘柄種別 CRUD（組み込み編集・カスタム追加・ドラッグ&ドロップ）
- 対象銘柄セレクト（SCHD相当の目標銘柄を任意に選択）
- データ管理（全体バックアップ JSON / 設定のみ JSON / 記録 CSV エクスポート）

## 対応口座種別

| コード | 表示名 | 非課税 | 備考 |
|--------|--------|--------|------|
| `nisa-growth` | NISA成長投資枠 | ✅ | 組み込み・編集可 |
| `nisa-tsumitate` | NISA積立投資枠 | ✅ | 組み込み・編集可 |
| `specific` | 特定口座 | — | 組み込み・編集可 |
| `old-nisa` | 旧NISA | ✅ | 組み込み・編集可 |
| カスタム | 任意 | 設定可 | 設定タブから追加 |
| iDeCo | iDeCo | ✅ | 別管理（idecoHoldings） |

## 対応資産種別

| コード | 表示名 | 備考 |
|--------|--------|------|
| `fund` | 投資信託 | 組み込み・編集可 |
| `domestic-stock` | 国内株式 | 組み込み・編集可 |
| `us-stock` | 米国株式 | 組み込み・編集可 |
| `other` | その他 | 組み込み・編集可 |
| カスタム | 任意 | 設定タブから追加可能 |
